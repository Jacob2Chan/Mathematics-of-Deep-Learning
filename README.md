# Mathematics of Deep Learning

## 深度学习的数学基础：学习与研究笔记

本仓库记录我在研究生阶段对深度学习数学基础的学习与研究，重点关注**群表示论、等变神经网络及几何深度学习**。内容涵盖课程讲义、数学证明、论文阅读和个人研究笔记，希望在持续学习与修订中，逐步整理成一套可供公开学习与交流的数学讲义。

这里既记录定义、定理与推导，也记录阅读中的疑问、不同理论之间的联系，以及尚待验证的研究思路。未完成的证明和猜想会明确标注，不作为已确立的结论。

## 重点方向

| 方向 | 关注的问题 |
| --- | --- |
| 群表示论 | 群作用、表示与不可约分解，以及对称性的代数描述 |
| 等变神经网络 | 等变映射、网络结构约束及表示论与模型设计之间的联系 |
| 几何深度学习 | 图、流形与其他几何结构上的学习，以及几何与对称性所提供的归纳偏置 |
| 深度学习基础理论 | 神经网络的函数表示、逼近能力与深度的作用 |

以上是仓库的长期关注方向，不代表各专题已经整理完成。

## 整理约定

- 讲义与证明注明符号、前提条件和结论适用范围，区分直观解释与严格证明。
- 论文笔记注明来源，区分原文结论、个人推导和未解决的问题。
- 研究笔记明确标注猜想、待验证步骤及阶段性结果。
- 新内容按课程讲义、数学证明、论文阅读、研究笔记分类，并补充首页索引；内容增多后再按专题建立子目录。
- 独立公式采用 `math` 代码块，行内公式使用美元符号与反引号组合的写法，减少 Markdown 转义冲突。参见 [GitHub 数学公式文档](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/writing-mathematical-expressions)。
- Markdown 为编辑源；离线 HTML 是独立阅读快照，内容修订后需同步重新导出。
